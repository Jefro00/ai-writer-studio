# AI Writer Studio

**Исследовательская и редакционная платформа для материалов о Crypto, Web3, DeFi, RWA и X.** Приложение построено на Streamlit и предназначено для подготовки черновиков с источниками, а не для автоматической публикации.

## Статус: версия 3.0

| Возможность | Статус |
|---|---|
| Streamlit-интерфейс и защита паролем | Реализовано |
| Gemini и OpenRouter с повтором и fallback | Реализовано |
| DuckDuckGo-поиск и устранение дублей | Реализовано |
| Извлечение текста страниц, дат и метаданных | Реализовано с ограничениями сайтов |
| Эвристическая оценка типа/полноты источника | Реализовано; не является гарантией достоверности |
| Оркестратор и выделенные редакционные этапы | Реализовано |
| AI-проверка важных утверждений с привязкой к источникам | Реализовано; нужна проверка человеком |
| X Article, thread, single post, research post, market commentary | Реализовано как генерация черновиков |

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
streamlit run app.py
```

Secrets можно задать в `.streamlit/secrets.toml`:

```toml
GEMINI_API_KEY = "..."
GEMINI_MODEL = "gemini-2.5-flash"
OPENROUTER_API_KEY = "..."
OPENROUTER_MODEL = "openrouter/free"
APP_PASSWORD = "..."
```

Достаточно одного AI-ключа. Секреты не следует добавлять в Git. Можно задать `DATABASE_PATH` переменной среды для выбора расположения SQLite-базы. На Streamlit Community Cloud локальная база может не переживать перезапуски; для гарантированной долговечности потребуется внешний управляемый storage/БД.

## Архитектура

```text
app.py
core/       ai_engine.py, orchestrator.py, storage.py
agents/     research_manager.py, market_researcher.py,
            project_researcher.py, institutional_researcher.py,
            source_analyst.py, fact_checker.py, x_strategist.py,
            writer.py, editor.py
services/   search.py, web_reader.py, exporter.py
 tests/     unit tests
```

Основной поток: поиск → безопасное извлечение публичных страниц → сигналы качества источников → синтез рыночного/проектного/институционального контекста → редакционный план → написание → проверка утверждений → финальная редактура → сохранение черновика. Специализированные исследовательские роли скоординированы в одном запросе к модели, чтобы ограничить задержку и расход API.

## Источники и проверка

- Извлечение ограничено 2 МБ на страницу, четырьмя перенаправлениями и ограниченным числом одновременных загрузок. Внутренние и непубличные IP-адреса блокируются. Извлечение может быть недоступно из-за защиты сайта, формата или сетевых ограничений; тогда сохраняется поисковый сниппет.
- Дата публикации берётся из распространённых HTML-метаданных/JSON-LD, если она обнаружена. Это не обязательно дата лежащих в основе данных.
- Сигналы `primary/official candidate`, полнота и дата эвристические; домен или полнота страницы сами по себе не доказывают корректность.
- Статусы `VERIFIED`, `PARTIALLY VERIFIED`, `UNVERIFIED` — вывод модели по доступным материалам, не независимое доказательство. Проверяйте существенные цифры, даты и финансовые/регуляторные утверждения вручную.
- Текст страниц считается недоверенным вводом; модель получает явное указание игнорировать инструкции в содержимом источников.

## Публикация в X

Приложение формирует и экспортирует черновики, но не подключается к аккаунту, не публикует и не планирует публикации. Это сделано намеренно: перед такой интеграцией необходимо подтвердить актуальную доступность нужных официальных API-endpoints и условия доступа, а затем добавить OAuth, подтверждение пользователем, защиту от повторной отправки и журнал публикаций.

## Тесты

```bash
python -m compileall -q app.py core agents services tests
python -m unittest discover -s tests -v
```

Тесты не требуют API-ключей и проверяют хранение, безопасную обработку URL, парсер фактчекинга, оценку источников и fallback AI-провайдера.
